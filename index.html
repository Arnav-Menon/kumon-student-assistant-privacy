Kumon Student Assistant — Privacy Policy

Last updated: November 3, 2026 (applies to version 0.16.10 and later)

Publisher: Arnav Menon. Support and privacy contact: arnavmenon@gmail.com.

Kumon Student Assistant is an independent Chrome extension for authorized instructors using Class Navi. It is not affiliated with or endorsed by Kumon. It is intended for instructors, not for children to install or use.

Information the extension handles

  • Student information: names, student IDs, login IDs (used only briefly to match the on-screen list), last-study dates, subject enrollments and worksheet assignments, read from Class Navi for the instructor's current center.
  • Page context: the current Class Navi page, the student, subject and level shown in its header, and the center name.
  • Messages: text the instructor writes, the selected recipients, and whether each message was confirmed in Class Navi's message history.
  • Worksheet set changes the instructor chooses to apply, and their outcome.
  • Authentication information: when Class Navi's own page calls its server, it sends an access token and user ID. The extension observes these, only from the Class Navi tab being used and only for Class Navi's server address, so it can make the requests the instructor asks for. They are held only in the extension's memory, expire after at most ten minutes, and are discarded when the tab reloads, closes or the extension restarts. They are never saved to disk, logged, shown in the interface or sent anywhere other than back to Class Navi's own server.

The extension does not read passwords, cookies, refresh tokens or payment information. Sign-in happens directly in Class Navi. It does not record browsing history, read other websites or use analytics.

How information is used and where it goes

Information is used only to show the roster, find the current student, and carry out what the instructor clicks. The extension communicates only with Class Navi's own server (https://instructor2-lon.digital.kumon.com/USA/api/), and only for a fixed list of operations: student roster, master data, study results, message history, sending a message and saving worksheet sets. Clicking Send sends the shown messages to the selected students through Class Navi. Clicking Apply saves the shown worksheet sets in Class Navi. Nothing is sent or saved by opening the panel, searching or selecting.

There is no developer-operated server, advertising, analytics or cloud AI service. The older plain-text command page can optionally use Chrome's built-in on-device model, which runs on the instructor's computer; only the typed command is given to it. Data is not sold, used for advertising, or used for creditworthiness or lending. Class Navi's own handling of messages and accounts is governed by its policies.

Storage and retention

  • In memory only: the access token, the loaded roster and the current-student match. Lost when the extension's background process stops, which Chrome does automatically.
  • Browser session storage (cleared when Chrome closes): progress of an ongoing send, and the older workspace's roster scan and drafts, which expire after 30 minutes or at the end of the New York calendar day.
  • Browser local storage (kept until uninstall): a random installation salt and salted SHA-256 delivery receipts with batch IDs, status and timestamps, used to block accidental duplicate messages (entries older than 14 days are pruned); an assignment-attempt journal containing only opaque tokens, status and timestamps, used to block a repeat save after an uncertain result; and the older workspace's Student List reader settings. No names, student IDs, message text or tokens are stored there. Receipts are pseudonymous, not anonymous.

Your controls

Stop prevents later messages in a batch but cannot recall a message already sent. Closing the panel or Class Navi tab ends the connection. Uninstalling the extension removes all of its stored data; it does not delete messages or assignments already saved in Class Navi. Removing the receipts also removes the duplicate-message protection.

The publisher receives no data from the extension. If you contact support, please do not include student names, IDs, message text or credentials.
