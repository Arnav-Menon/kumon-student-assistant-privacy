Kumon Student Assistant — Privacy Policy

Last updated: October 30, 2026

Publisher: Arnav Menon. Support and privacy contact: arnavmenon@gmail.com.

Kumon Student Assistant is an independent Chrome extension for authorized instructors using Class Navi. It is not affiliated with or endorsed by Kumon. It is intended for instructors, not for children to install or use.

Information the extension handles

At the instructor's request, the extension reads displayed student names, student identifiers and Last Study dates from the selected Class Navi Student List. It also reads page structure needed for roster navigation and native messaging. It processes instructor-entered messages, draft revisions and approvals, selected recipients and delivery outcomes.

The extension does not read passwords, cookies, session tokens, authorization headers or payment information. Login happens directly in Class Navi. It does not record cross-site browsing history, capture unrelated pages, collect existing message histories or use analytics.

Purpose and transmission

Information is used only to review student activity, prepare and approve communications, and operate Class Navi's own messaging UI when the instructor clicks Send all approved. Approval by itself sends nothing; the Send click starts delivery without a further confirmation screen. Native UI interactions cause Class Navi to transmit the approved messages to the displayed student-message destinations using the instructor's existing browser session.

There is no developer-operated backend, advertising, analytics, third-party AI service or external message delivery service. The extension does not sell user data or use it for advertising, creditworthiness or lending. Data is not transferred to a developer server. Class Navi's own processing of messages/accounts is governed by the platform's policies.

Storage and retention

Student records, raw names/IDs, message bodies, approvals and jobs stay in restricted chrome.storage.session. They logically expire 30 minutes from scan start or at New York day rollover, and clear on scan replacement/clear, source-tab closure or extension/browser lifecycle. Expiry is enforced when accessed/processed; immediate physical deletion while Chrome is idle is not guaranteed. Unsaved edits can remain in an open review page until it closes or the UI clears them.

Adapter configuration and duplicate-prevention data persist in chrome.storage.local. The latter consists of a random installation salt, salted SHA-256 keys, batch IDs, outcome enums and timestamps. Raw names, student IDs and messages are not stored in the local delivery journal. These hashes are pseudonymous operational data, not a guarantee of anonymity. Entries older than 14 days are logically pruned when the journal is accessed; physical removal while the extension is idle is not guaranteed.

Controls and deletion

Clear results removes the current session scan and drafts. Revoke approvals removes local approval but cannot recall an issued message. Stop prevents later attempts but cannot undo a Send click already issued. Uninstalling the extension removes its Chrome extension storage; it does not delete messages already stored by Class Navi. Clearing extension storage/uninstalling also removes duplicate-prevention receipts, so previously sent/uncertain reminders may no longer be locally blocked.

The publisher receives no automatic telemetry or student records. If an instructor voluntarily contacts support, do not include student names, IDs, message text or credentials in the support request. The extension does not implement a support-data upload feature.

Changes and contact

Update this policy if data practices change and disclose changes as required. For privacy or support questions, contact arnavmenon@gmail.com.
